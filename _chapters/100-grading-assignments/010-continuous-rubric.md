## Intent
Students and instructors use a visual continuum-based rubric that depicts achievement as progressive zones rather than discrete boxes.

## Problem
Matrix-style rubrics create several challenges for assessment. Instructors struggle to write distinct descriptors for each cell, often manufacturing differences using vague adjectives like "good" versus "very good" rather than describing actual behavioral changes. The matrix format pressures instructors to fill every box even when a criterion doesn't warrant five distinct levels, resulting in repetitive or meaningless descriptors. When descriptors are ambiguous, assessors make subjective judgments that compromise grading reliability, particularly during moderation when multiple markers must reach consensus. Students also struggle to understand what distinguishes one achievement level from another when descriptors rely on subtle word changes rather than clear behavioral differences. The rigid cell structure forces assessors to commit to a single standard even when student work falls between levels, preventing holistic judgment.

## Solution
The Continua Model (also called a Guide to Making Judgments or GTMJ) replaces the matrix format with visual continuums that depict learning as progressive development rather than discrete categories. The approach has four key design principles:

1. **Standards continuum**: Each criterion is represented as an arrow extending from lowest to highest achievement, with the arrow tip extending beyond the highest descriptor to acknowledge that excellence may exceed definition.

2. **Variable descriptors**: Each criterion contains only the number of descriptors needed to show progression. Some criteria may have three levels, others five, eliminating the need to manufacture descriptors to fill boxes.

3. **Nested descriptors**: Each higher descriptor includes all previous behaviors plus the new distinguishing quality. Descriptors identify only what changes at each level rather than repeating all expectations. A student achieving the highest level inherently demonstrates all lower-level behaviors.

4. **Standards zones**: Achievement levels are positioned as "regions of quality" along the continuum rather than fixed boundaries, acknowledging that even well-written standards cannot be defined with absolute precision. Assessors can mark anywhere within or between zones.

The visual arrow format and nested language make progression explicit: assessors and students can see exactly what behavior must be added to move up the continuum.

## Applicability
The continua model works best when assignments assess multiple learning outcomes or concepts with varying complexity, making it particularly suitable for specifications grading or standards-based grading contexts. It streamlines grading in medium-sized classes by reducing subjective judgment calls about borderline work—assessors can mark within regions rather than committing to fixed cells.

The model benefits courses where:
- Multiple assessors must achieve consistency (the explicit descriptors reduce interpretation variance)
- Students need clear scaffolding to understand progression (the nested structure shows exactly what to add)
- Assessment tasks vary in complexity across criteria (some may need three levels, others five)

The approach requires initial investment: instructors must identify the truly discriminating behaviors at each level rather than filling boxes. For courses with highly complex, multidimensional tasks, the continua model may actually reduce the oversimplification that occurs when forcing rich performance into matrix cells. However, instructors accustomed to matrix formats will need to shift their thinking about how to describe standards.

## How to Implement

### Design the Continuum Structure
For each assessment criterion, create an arrow spanning from lowest to highest achievement. Extend the arrow tip beyond your highest descriptor to acknowledge that exceptional work may exceed description. Position standard zones (e.g., "Does Not Meet," "Approaches," "Meets," "Exceeds") as regions along each arrow rather than at fixed points.

### Write Nested Descriptors
Start with your baseline expectation—what behavior defines the lowest passing standard? Write this as your first descriptor. For each higher level, identify only the new or enhanced behavior that distinguishes it from the previous level. Use action verbs that describe observable behaviors (e.g., "synthesize," "critically reflect," "evaluate") rather than quality adjectives (e.g., "good," "excellent"). Each descriptor should answer: "What must the student add or do differently to reach this level?"

Example progression for a single criterion:
- **Approaching**: Defines key concepts and applies them to scenarios covered in class
- **Proficiency**: [includes above] + Applies concepts to new scenarios not covered in class
- **Mastery**: [includes above] + Synthesizes multiple concepts to analyze complex situations

### Vary Descriptor Quantity by Criterion
Let the depth of each criterion determine how many levels you define. If a criterion has genuine progression across five levels, include five descriptors. If another criterion really only differentiates two or three ways, stop there. Do not force descriptors to achieve symmetry across criteria.

### Mark Within Regions
When assessing student work, determine which descriptor best captures the highest behavior demonstrated, then mark within or between the standard zones as appropriate. The continuum format allows you to indicate a student is "approaching proficiency" or "solidly at mastery" without forcing a binary cell choice.

### Use for Moderation
During moderation meetings, focus discussion on whether student work demonstrates the specific behaviors listed in descriptors rather than debating interpretations of quality adjectives. The explicit, nested language provides objective evidence markers can verify, reducing status-based acquiescence where junior markers simply agree with senior colleagues.

## Examples

**Visual Layout**: Each criterion appears as a horizontal arrow with descriptors positioned along it. Standard zones (e.g., "Does Not Meet," "Approaches," "Meets," "Exceeds") span regions of the arrow rather than appearing in discrete columns.

**Nested Descriptor Example (Critical Thinking)**:
- Level 1: Identifies main arguments in sources
- Level 2: [includes above] + Evaluates the validity of arguments using evidence
- Level 3: [includes above] + Synthesizes multiple perspectives to develop original position

**Variable Standards Example**: In an education course GTMJ, the "Pedagogical Knowledge" criterion might have five descriptors showing fine-grained progression, while "Professional Communication" might have only three descriptors because fewer meaningful distinctions exist.

**Grading Example**: On a 0-4 scale where 3 indicates proficiency, an assessor might mark a student at 3.5 within the "Proficiency" zone to indicate solid achievement of that standard, or at 2.5 between "Approaches" and "Meets" to indicate work is stronger than approaching but doesn't quite meet all proficiency behaviors.
